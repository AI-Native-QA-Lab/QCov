# CLI Implementation Record

## Scope

Task 6 supplies the local QCov commands: `init`, `scan`, `gaps`, `inspect`,
`check`, and `report`. It supports English or Chinese presentation and stable
Markdown/JSON modes.

## Exit behavior

`check` returns 0 for covered input, 2 for partial/missing input, 3 for
unknown-only input, and 4 for input/configuration errors. Other report commands
return 0 after successful evaluation.
