# 1.0 真实项目案例骨架

## 范围

在本仓库新增三个只含元数据、显式 obligation 和离线复现说明的案例包：
`ai-native-qa-agents`（Python pytest coverage）、`ai4se-demo-project`
（Java JUnit JaCoCo）与 `naodeng.com.cn`（TypeScript Playwright）。未修改
任何外部项目，也没有复制其源码、测试结果或敏感配置。

## 案例运行验证

- `ai-native-qa-agents`：在固定提交的临时克隆中使用 QCov 的 Python 3.12
  环境执行 `PYTHONPATH=packages .venv/bin/python -m pytest -q`，结果为
  `90 passed`。这只是源项目测试通过，不代表 QCov 已导入报告或满足 Release Gate。
- `ai4se-demo-project`：在固定提交的临时克隆和隔离 Maven 本地仓库中执行
  `mvn -q -Dmaven.repo.local=<temporary>/m2 test`。Maven 因环境无法解析
  `repo.maven.apache.org` 上的 Spring Boot parent POM 而在测试前受阻。
- `naodeng.com.cn`：在固定提交的临时克隆中执行 `cd tests && npm run test:e2e`；
  因隔离副本未安装 Playwright 可执行文件而在测试前受阻。

## 未满足的 Release Gate

三个项目现各有 10 条可追溯到固定提交的 source-derived obligation，但仍待项目
负责人审阅；尚无脱敏报告的导入与显式映射。Java 案例固定提交的 `backend/pom.xml` 也尚未配置 JaCoCo。Python 案例的
源项目测试已通过，但不构成导入或映射证据；Java 与 Playwright 案例分别受 Maven
依赖网络与缺少 Playwright 依赖阻塞。因此所有案例的 Release Gate 均保持 `NOT_MET`。
