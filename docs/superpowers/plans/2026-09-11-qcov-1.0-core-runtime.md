# QCov 1.0 核心运行时实施计划

> **面向执行代理：** 必须使用 `superpowers:executing-plans` 或 `superpowers:subagent-driven-development`，按任务逐项执行，并用复选框（`- [ ]`）记录进度。

**目标：** 实现确定性的 Change → Obligation Impact、`qcov affected`、稳定的 `qcov.impact/v1` 输出，以及进程内 Adapter SDK 与 JaCoCo XML inventory reader。

**架构：** Impact 逻辑放入纯函数引擎：它只接收仓库相对路径、显式 mapping 和既有 Gap Engine 结果；CLI 仅负责直接文件或本地 Git 快照输入。Adapter SDK 复用现有 `ScanResult`/`ScanDiagnostic`，JaCoCo 只产出 inventory，绝不产生义务证据。

**技术栈：** Python 3.11+、Pydantic、Typer、标准库 `xml.etree.ElementTree`、pytest。

```python
@app.command()
def impact(
    config: Annotated[Path, typer.Option(exists=True, readable=True)],
    impact_config: Annotated[Path, typer.Option("--impact-config", exists=True, readable=True)],
    changed_file: Annotated[list[str], typer.Option("--changed-file")] = [],
    base: Annotated[str | None, typer.Option()] = None,
    head: Annotated[str | None, typer.Option()] = None,
    repo: Annotated[Path | None, typer.Option()] = None,
    output_format: OutputFormat = "markdown",
) -> None: ...
```

直接模式要求至少一个 `--changed-file`；Git 模式要求同时提供 `--base` 与 `--head`，两种模式互斥。新增 `changed_files_between(repo, base, head)`，通过 `git diff --name-only -z base head` 获取仓库相对 POSIX 路径。`qcov diff` 使用同一函数填充 `changedFiles`，但不改变既有 `obligations` delta 语义。
