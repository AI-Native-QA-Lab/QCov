# QCov 1.0 文档 onboarding 实施计划

**目标：** 为 QCov 1.0 的真实项目验证准备可执行、双语且不越权的首次使用路径。

**范围：** `README.md`、`README.zh-CN.md`、`docs/en/getting-started.md`、
`docs/zh-CN/getting-started.md`、文档契约测试与中文过程记录。不会新增 CLI、修改核心代码、
修改外部项目或改变示例协议数据。

## 验收约束

- 命令必须与当前 Typer CLI 一致，并以仓库已提交 fixture 验证。
- 5 分钟流程固定为：安装、`gaps`、`scan`、`map preview`、映射后的 `gaps`、本地 Git
  `diff`、`policy check`。
- Python、Java/JUnit、TypeScript/Playwright 的说明只描述现有扫描和显式 mapping 边界。
- `qcov impact` 与 `qcov affected` 尚未实现，只能作为未实现能力的澄清出现，不能作为可运行命令。
- coverage.py、LCOV、scanner inventory、AI proposal 与 agent 输出均不能被表述为证据或门禁权威。
