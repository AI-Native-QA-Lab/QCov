# QCov 1.0 文档与上手计划

> **面向执行代理：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项执行。本计划使用复选框（`- [ ]`）跟踪进度。

**目标：** 在用户阅读源码前，让新用户可以安装 QCov、理解边界并完成第一次运行。

**架构：** 双语 README 作为简洁入口；详细安装、配置、示例和排障放入配对的公开指南。每条公开命令都在本地运行，并保持 QCov 仅本地执行、显式 mapping 才具备权威性的边界。

**技术栈：** Markdown、Python 3.11+、pip、pytest 文档断言。
