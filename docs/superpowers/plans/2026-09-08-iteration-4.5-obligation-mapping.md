# Iteration 4.5 显式义务映射实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or implement task-by-task with TDD. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 junit/playwright inventory 经声明式 `EvidenceMapping` 提升为可进入 Gap Engine 的 `QualityEvidence`，并提供 `qcov map preview`。

**Architecture:** 严格协议模型 + config `mapping` 路径；scan 保留 inventory records；纯 `engine.mapping` 物化证据；CLI `--config` 合并手写与映射产物；报告附加 `mappingDiagnostics`。

**Tech Stack:** Python 3.11+、Pydantic v2、Typer、PyYAML、pytest、Ruff、mypy。

**Spec:** `docs/superpowers/specs/2026-09-08-iteration-4.5-obligation-mapping-design.md`

## 全局约束

- 先 RED 再 GREEN；不推断义务；coverage/lcov 不可作 producer。
- 无 mapping 时行为不变；无 `--config` 不隐式映射。
- 时间戳只来自 mapping 文件；artifact 禁止绝对路径。
- 最终门禁：`pytest`、`ruff check .`、`mypy qcov`、`python -m build`、`git diff --check`。
