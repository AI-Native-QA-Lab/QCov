# QCov MVP Repository Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a reproducible Python CLI that identifies unproven quality evidence for explicit testing obligations.

**Architecture:** Versioned YAML/JSON obligations and evidence are validated by Pydantic models. A pure deterministic engine computes per-dimension and per-obligation states; adapters normalize producer data at the edge; Typer commands render localized Markdown or stable JSON.

**Tech Stack:** Python 3.11+, Pydantic v2, Typer, PyYAML, Rich, pytest, Ruff, mypy, JSON Schema, GitHub Actions, Mermaid.

**Spec:** `docs/superpowers/specs/2026-09-02-qcov-mvp-design.md`

## Global Constraints

- [ ] Python `>=3.11`; all runtime dependencies live in `pyproject.toml`.
- [ ] Core behavior is deterministic, local, and network-free.
- [ ] Protocol keys, enums, CLI flags, and error IDs stay English; presentation supports `en` and `zh-CN`.
- [ ] Never convert UNKNOWN to PASS or calculate an aggregate quality score.
- [ ] Exclude AI, Git delta, database persistence, UI, external plugins, and policy enforcement from the MVP.
- [ ] Preserve process evidence in `docs/superpowers/`, `docs/adr/`, and `docs/process/`.

## File Structure

| Path | Responsibility |
| --- | --- |
| `pyproject.toml`, `qcov/` | installable package, tooling, CLI entry point |
| `qcov/models/` | strict protocol models and input loading |
| `qcov/engine/` | gap calculation, errors, JSON/Markdown reports |
| `qcov/adapters/` | adapter protocol and marker-based pytest reference adapter |

| `docs/diagrams/`, `docs/adr/`, `docs/process/` | architecture, decisions, and execution evidence |
