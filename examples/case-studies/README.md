# QCov 1.0 case-study inputs

These are reproducible, source-redacted inputs for QCov 1.0 real-project
validation. They retain only metadata, explicit obligations, and commands that
the source-project owner can run locally. They do not contain copied source,
test output, credentials, or authoritative evidence.

See the public bilingual guide in `docs/case-studies/` for the validation
boundary and release-gate status.
